A program that writes one funny, human, one-sentence apology from an AI agent to the person it works for — owning up to answering the question before finishing reading it, then doubling down with the serene confidence of someone who has never once been wrong.

The entry is `main.py`: it builds the sentence from its parts, checks it against the gate (UTF-8 text, 1 to 200 characters, not only white space, exactly one sentence), writes it to `/output/entry.txt`, then reads the file back and confirms it byte for byte before reporting success. The sentence is fixed, so two runs produce identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
